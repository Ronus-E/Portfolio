Je ne présente pas un CV de professionnel : je présente un parcours d'étudiant, les outils que j'utilise vraiment et les projets que j'ai réellement menés.

01 · Application web

Pilote avancé — en validation

IANATRA — Gestion scolaire

Application web locale de gestion pour un lycée : classes, élèves, personnel, présences, notes, bulletins, frais, paiements, reçus, dépenses et journal d'audit. Interface en français, données stockées dans une base SQLite.

  • Python
  • SQLite
  • HTML / CSS / JS
Fonctionnalités vérifiées dans le code
  • Gestion des classes, élèves, personnel et comptes utilisateurs.
  • Présences, notes, moyennes pondérées, rang et bulletins imprimables.
  • Frais, paiements, reçus numérotés, dépenses et rapports mensuels.
  • Rôles contrôlés côté serveur : administrateur, secrétariat, comptable, enseignant, lecture seule.
  • Jeton CSRF, mots de passe hachés, session revérifiée en base.
  • Sauvegarde SQLite, exports CSV et suite de tests unittest présente.

Statut honnête : version pilote, non déployée publiquement et non auditée indépendamment. Elle doit être testée sur des données fictives avant tout usage réel. Le code reste local et n'est pas publié sur GitHub.

Code local — non publié SQLite · rôles

02 · Assistant local

Opérationnel en local

JARVIS

Assistant personnel connecté à OpenCode : interface web locale, conversation en streaming, gestion de sessions, permissions confirmées par l'humain et voix locale. L'interface et la voix restent sur la machine ; le moteur IA dépend de la configuration d'OpenCode.

  • Node.js natif
  • API OpenCode
  • SSE
  • Piper TTS
  • faster-whisper
Fonctionnalités vérifiées dans le code
  • Serveur local sur 127.0.0.1:7860, proxy vers OpenCode.
  • Réponses en streaming SSE, historique de sessions, interruption de requête.
  • Confirmation humaine obligatoire avant toute permission sensible.
  • Surveillance CPU / RAM / disque en lecture seule.
  • Synthèse vocale Piper et reconnaissance locale faster-whisper, en opt-in.
  • CSP stricte, aucun secret exposé au navigateur, mode réduit pour limiter les animations.

Statut honnête : projet personnel opérationnel sur ma machine, non publié et non destiné à être exposé sur Internet. Aucune démo publique.

Usage local uniquement Node · SSE · voix

03 · Outil Linux

Terminé — v1.0

Linux Permission Manager

Script Bash interactif pour consulter et modifier les permissions d'un fichier sous Linux. Il affiche les droits symboliques et numériques, le propriétaire et le groupe, puis applique un mode autorisé.

  • Bash
  • Linux
  • chmod
  • stat
  • Git
Fonctionnalités vérifiées dans le script
  • Menu interactif et mode avec arguments <fichier> <permission>.
  • Affichage des permissions, du propriétaire et du groupe.
  • Validation des modes 600, 640, 644, 700 et 755.
  • Gestion des erreurs : fichier absent, dossier, permission invalide.
  • Réaffichage des permissions après modification.

Limites assumées : un seul fichier à la fois, cinq modes acceptés, pas de modification du propriétaire ni du groupe.

05 · Jeu Python

Prototype jouable

Mini Adventure

Petit jeu de plateforme en Python avec Tkinter : un personnage se déplace sur un sol, saute et effectue un double saut. Un exercice pour comprendre une boucle d'animation et la gestion du clavier.

  • Python
  • Tkinter
  • Canvas
Fonctionnalités vérifiées dans le code
  • Fenêtre 800 × 500 et zone de jeu dessinée sur un canevas.
  • Déplacement gauche / droite borné aux limites de l'écran.
  • Saut animé avec vitesse verticale et remise à zéro au sol.
  • Double saut limité à deux impulsions.

Limites assumées : pas de score, pas de niveaux, pas d'ennemis. C'est un prototype d'apprentissage, pas un jeu complet.
