À propos

Je suis étudiant en informatique, en phase d'apprentissage. Mon parcours actuel est orienté vers Linux, le terminal, le Bash, Git / GitHub, la programmation et la cybersécurité.

Ma façon d'apprendre est simple : comprendre une notion, la pratiquer dans un environnement réel, tester, corriger les erreurs, puis construire un petit projet avec. C'est pour cela que j'utilise Linux au quotidien plutôt que de me limiter à la théorie.

Je considère ce portfolio comme un reflet fidèle de là où j'en suis aujourd'hui : il évoluera au même rythme que mes compétences.

Projets

Une seule entrée pour l'instant : mon premier projet d'apprentissage. Rien d'inventé pour remplir la page.

linux-permission-manager

Projet d'apprentissage

Petit projet d'apprentissage réalisé en Bash pour pratiquer la gestion et l'inspection des permissions Linux.

Objectif

Comprendre concrètement les permissions Linux en travaillant dessus : inspecter les permissions d'un fichier et les modifier (chmod symbolique et numérique), tout en pratiquant l'écriture d'un script Bash.

Technologies utilisées

  • Bash
  • Linux
  • chmod
  • stat

Ce que je mets en pratique

Script principal perm-manager.sh : variables Bash, conditions if, paramètres de script ($1), tests, et utilisation de commandes Linux dans un script.
