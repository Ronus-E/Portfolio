Linux Permission Manager

Terminé — v1.0

Petit outil personnel écrit en Bash pour consulter et modifier les permissions d'un fichier sous Linux, à travers un menu interactif ou des arguments en ligne de commande.

Le besoin

Comprendre concrètement les permissions Linux en travaillant dessus : les lire (symboliques et numériques), identifier le propriétaire et le groupe, puis les modifier proprement avec chmod, tout en pratiquant l'écriture d'un script Bash structuré.

Fonctionnalités existantes

  • Menu interactif (informer, modifier, quitter) et mode avec arguments.
  • Affichage des permissions symboliques et numériques.
  • Affichage du propriétaire et du groupe.
  • Vérification qu'un chemin est bien un fichier et détection des dossiers.
  • Validation des modes autorisés : 600, 640, 644, 700 et 755.
  • Modification des permissions avec chmod.
  • Gestion des erreurs (fichier inexistant, dossier, entrée invalide).
  • Réaffichage des permissions après modification.

Technologies utilisées

  • Bash
  • Linux
  • chmod
  • stat
  • Git
  • GitHub

Compétences mises en pratique

  • Bash : variables, arguments, fonctions, conditions if, structures case, boucles while, read et codes de retour.
  • Permissions Linux et commandes chmod et stat.
  • Validation des entrées et gestion des erreurs.
  • Organisation d'un petit projet et documentation en Markdown.
  • Publication du code et du README sur GitHub.

Limites actuelles

Seules cinq permissions sont acceptées, un seul fichier est traité à la fois, et le script ne modifie ni le propriétaire ni le groupe. Ces limites sont assumées : le projet reste un support d'apprentissage.

Améliorations possibles

Non développées dans la version 1.0 — pistes pour une future version.

  • Accepter davantage de permissions.
  • Traiter plusieurs fichiers à la fois.
  • Ajouter les options --help et --version.
  • Demander une confirmation avant modification.
  • Améliorer les tests automatiques et la journalisation des opérations.
